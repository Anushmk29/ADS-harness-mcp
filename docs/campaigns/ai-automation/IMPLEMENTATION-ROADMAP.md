| Metric | Pass | Fail |
|--------|------|------|

### Week 5–8: Learning + First Optimization

**Week 5–6 Rules:**
- ❌ Do NOT edit ads with < ₹500 spend
- ❌ Do NOT change bidding strategy (still in learning)
- ✅ DO check: are leads coming? Even 1-2/day is normal
- ✅ DO check: is Lead event firing in Events Manager?

**Week 7 First Optimization Pass:**
- Pause any ad with ₹1,000+ spend and 0 leads
- Note best CTR creative
- Check CPL (even if high — this is learning phase)

**Week 8: Decision Gate #2**

| Metric | Pass | Fail |
|--------|------|------|
| Total leads (Weeks 5–8) | ≥30 | <15 |
| Blended CPL | < ₹500 | >₹800 |
| At least 1 deal closed | Yes | No |
| Learning phase | Exited or in progress | "Learning Limited" >50% |

**If PASS →** Increase budget to ₹500/day (Option 2)
**If PARTIAL →** Stay at ₹350/day for 2 more weeks
**If FAIL →** Audit: form, creative, targeting, tracking. Rebuild.

### Week 9–12: Scaling

| Task | Detail |
|------|--------|
| Budget | Increase to ₹500/day (if Week 8 gate passed) |
| Kill Rule | Pause any ad with ₹2,000+ spend and CPL > 2x average |
| Scale Rule | +20% budget on ads with CPL < 50% of average |
| Bidding | If 50+ conversions → switch to Cost Cap (1.5x CPL) |
| Creative | Launch PB-4 testimonial (if not already live) |
| Retargeting | Scale to ₹150/day (audience now 3,000–5,000) |
| New Creative | Launch 1 new concept (backup from brief or new angle) |

### Week 13–16: Optimization + Expansion

| Task | Detail |
|------|--------|

| Geo | If CPL < ₹200 → test adjacent city |

| Creative Refresh | Retire any creative with CTR drop >20% over 14 days |
| 90-Day Review | Full P&L, LTV:CAC, creative audit, tracking audit |

## Weekly Ritual (15 minutes, every Monday)

```
□ Check Ads Manager:
  □ Spend vs. budget on track?
  □ Any ads in "Learning Limited"? (>50% = problem)
  □ Any ad with ₹500+ spend and 0 leads? → PAUSE (Phase B only)
  □ CTR trend: up, flat, or down?
  □ Frequency (7-day): < 3.0 (prospecting)? < 8.0 (retargeting)?

□ Check Events Manager:
  □ Lead events arriving?
  □ EMQ score stable or improving?
  □ Dedup rate ≥ 90%?

□ Check Lead Form (Phase B only):
  □ How many new leads this week?
  □ Quality: did sales call them? How many qualified?

□ Write 3 bullet notes:
  □ What's working?
  □ What's not?
  □ One action for next week?
```

## Bi-Weekly Ritual (30 minutes, every other Friday)

```
□ Kill/Scale decisions:
  □ Any ad to pause? (CPL > 3x average for 2 weeks)
  □ Any ad to scale? (+20% budget max)

□ Creative refresh check:
  □ Any creative with CTR drop >20% over 14 days?
  □ Any creative past 21-day refresh cycle?
  □ New creative ready to launch?

□ Audience check:
  □ Retargeting audience size adequate?
  □ Any audience overlap > 30%?

□ Budget reallocation:
  □ 70/20/10 ratio maintained?
```

## Monthly Ritual (1 hour, last Friday of month)

```
□ Full P&L reconciliation:
  □ Ad spend vs. revenue attributed
  □ ROAS, MER, LTV:CAC
  □ CAC by creative/audience

□ Creative pipeline:
  □ Score all active creatives (Andromeda diversity)
  □ Plan next month's production (1–2 new concepts)
  □ Retire fatigued assets

□ Tracking health:
  □ EMQ trend (4-week)
  □ Dedup rate
  □ Any broken events?

□ Strategy review:
  □ Funnel working? (Impressions → Clicks → Leads → Calls → Deals)
  □ Biggest leak?
  □ #1 priority for next month?
  □ Budget adjustment?
```

## Risk Mitigation Timeline

| Week | Risk | Mitigation |
|------|------|-----------|
| 2 | No engagement in first 3 days | Normal — keep running. Check pixel is correct. |
| 3 | CPM > ₹300 | Narrow geo or test different creative. Don't panic. |
| 4 | Retargeting audience < 1,000 | Extend Phase A by 2 weeks. Don't jump to Phase B with tiny audience. |
| 5–6 | No leads in first 2 weeks | Normal — learning phase. Check form + tracking. Keep running. |
| 7–8 | CPL > ₹800 | Check form (too hard? too easy?). Check creative CTR. Narrow geo. |
| 9–10 | Creative fatigue | Launch backup concept. Have 2 spare concepts ready. |
| 11–12 | Lead quality declining | Tighten form. Add qualifying question. Shift to retargeting. |
| 13–16 | Budget scaling → CPL rising | 20% rule. Don't scale too fast. Add audiences before increasing budget. |
