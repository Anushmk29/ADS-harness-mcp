# Budget Plan: Meta Ads — AI Automation Services
**Philosophy:** Two-phase. Build audience first, then convert.
**Phase A:** ₹200/day (₹6,000/month) — Awareness
**Phase B:** ₹350–500/day (₹10,500–15,000/month) — Lead Gen + Retargeting
**Currency:** INR

---

## Phase A: Awareness (Weeks 1–4)

### Monthly Budget: ₹6,000

| Campaign | Daily Budget | Monthly | % of Total |
|----------|-------------|---------|-----------|
| Awareness (Link Clicks) | ₹200 | ₹6,000 | 100% |

### What You're Buying
- ~60,000–180,000 impressions (blended CPM ₹80–250)
- ~600–1,800 clicks (CTR 1.0–2.0%)
- ~150–450 video completions (75%+ watch)

| Metric | Week 2 Target | Week 4 Target |
|--------|--------------|--------------|
| CPM (₹) | < ₹300 | < ₹200 |
| CTR | ≥0.8% | ≥1.2% |

| Website Visitors (cumulative) | 500+ | 2,000+ |
| Retargeting Audience Size | 500+ | 2,000–5,000 |

### Phase A Decision Gate (End of Week 4)
| Metric | Pass | Fail |
|--------|------|------|
| Retargeting audience size | ≥2,000 | <1,000 |
| CTR | ≥1.0% | <0.5% |
| Website visitors (cumulative) | ≥1,500 | <500 |
| Creative engagement | At least 1 ad with CTR >1.5% | All ads CTR <0.5% |

**If PASS →** Move to Phase B (add Lead Gen + Retargeting)
**If PARTIAL (2 of 4) →** Extend Phase A by 2 weeks
**If FAIL →** Pause. Audit creatives. Check targeting. Rebuild.

## Financial Model (Detailed)

### Assumptions
```
Average Deal Value:    ₹30,000 (one-time project)
Retainer Upsell (50%): ₹10,000/month × 6 months = ₹60,000
Blended LTV:           ₹45,000 (60% one-time + 40% retainer)
Gross Margin:          70%
Gross LTV:             ₹31,500
```

### Phase B Option 1 (₹350/day)

```
Monthly Ad Spend:       ₹10,500
Blended CPL:            ₹250
Leads Generated:        42
Lead → Call Rate:       30%
Calls Booked:           12.6 (round to 12)
Call → Close Rate:      20%
Deals Closed:           2.4 (round to 2-3)
Revenue (2.4 × ₹30,000): ₹72,000
ROAS:                   6.9x
Gross Profit:           ₹50,400
Net Profit after Ads:   ₹39,900
Profit Margin on Ads:   380%
```

### Phase B Option 2 (₹500/day)

```
Monthly Ad Spend:       ₹15,000
Blended CPL:            ₹200
Leads Generated:        75
Lead → Call Rate:       30%
Calls Booked:           22.5 (round to 22)
Call → Close Rate:      20%
Deals Closed:           4.4 (round to 4-5)
Revenue (4.4 × ₹30,000): ₹1,32,000
ROAS:                   8.8x
Gross Profit:           ₹92,400
Net Profit after Ads:   ₹77,400
Profit Margin on Ads:   516%
```

### Break-Even Analysis

```
Break-Even CPL = Average Deal Value × Gross Margin × Close Rate

= ₹30,000 × 0.70 × 0.20
= ₹420

Maximum profitable CPL = ₹420

At CPL ₹250: You're 40% below break-even → healthy margin
At CPL ₹200: You're 52% below break-even → excellent
At CPL ₹400: You're 5% below break-even → tight but workable
At CPL ₹500: You're 19% ABOVE break-even → NOT profitable
```

> **Key insight:** Your maximum profitable CPL is ₹420. If Meta delivers leads at ₹100–300, you have a 30–75% margin cushion. The math is very favorable.

### LTV:CAC

```
CAC = Ad Spend / Deals Closed

Option 1 (₹350/day): CAC = ₹10,500 / 2.4 = ₹4,375
Option 2 (₹500/day): CAC = ₹15,000 / 4.4 = ₹3,409

LTV:CAC:
  Option 1: ₹31,500 / ₹4,375 = 7.2:1
  Option 2: ₹31,500 / ₹3,409 = 9.2:1

Benchmark: 3:1 is healthy. You're 2.4–3x above that.
```

## Scaling Path

| Phase | Monthly Budget | Daily | Focus |
|-------|---------------|-------|-------|
| Phase A (Weeks 1–4) | ₹6,000 | ₹200 | Awareness + audience building |
| Phase B1 (Weeks 5–8) | ₹10,500 | ₹350 | Lead gen + retargeting (conservative) |
| Phase B2 (Weeks 9–12) | ₹15,000 | ₹500 | Scale winners +20%/week |
| Phase C (Weeks 13–16) | ₹20,000–25,000 | ₹650–800 | Add lookalike, WhatsApp, new geo |
| Phase D (Month 5+) | ₹25,000–50,000 | ₹800–1,650 | Add Google/LinkedIn if justified |

### Scaling Rules
- **20% Rule:** Never increase any ad set budget by more than 20% in a 7-day window
- **New Ad Set Rule:** When adding a lookalike ad set, give it 20% of the primary ad set's budget
- **Creative Refresh:** Launch 1 new concept per month to prevent fatigue
- **Geo Expansion:** If CPL < ₹200 in home market, test adjacent city

## What NOT to Spend On (Low-Budget Discipline)

| Temptation | Why to Skip | When to Consider |
|------------|------------|-----------------|
| Multiple ad sets per campaign | Splits ₹200 across sets = algorithm can't optimize | Phase C+, 100+ leads |
| Narrow interest targeting | Kills Andromeda's creative-matching | Never (use Advantage+ Audience) |
| LinkedIn Ads | ₹50,000+/month minimum viable | Phase D, budget > ₹50,000/mo |
| Google Ads (Search) | CPC ₹50–200 for B2B terms; needs separate strategy | Phase C, if Meta CPL < ₹200 |
| Boosted posts | No conversion optimization; worst CPL | Never for lead gen |
| Story-only creative | Limits delivery to 9:16 | As supplement, not primary |
| Multiple languages simultaneously | Splits budget; test one at a time | Phase C, test Hindi-only ad set |
| YouTube ads | CPM higher than Meta for B2B; needs video pipeline | Phase D, 2+ video assets |
